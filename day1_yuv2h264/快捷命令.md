* 关机

```shell
adb shell poweroff

```

* 删除h264文件

```shell
adb shell rm -f /userdata/av/out.h264

```


* see av file

```shell
adb shell ls /userdata/av/

```


* 用adb 将/userdata/av/out.h264 传送到 mac上

```shell
# pull 是电脑上的 adb 命令，不要加 shell；目标是目录时文件名保持 out.h264
adb pull /userdata/av/out.h264 /Users/dev/Documents/AV/rk_work/day1_yuv2h264/result_file_from_rk/

```
