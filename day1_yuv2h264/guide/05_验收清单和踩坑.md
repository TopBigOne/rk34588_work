## 2. 环境和编译的坑

| 现象 | 原因 | 解决办法 |
|---|---|---|
| `'rockchip/rk_mpi.h' file not found`，编译命令里是 `/usr/bin/c++` | CLion 的 `RK3588-Debug` 没配交叉编译工具链 | CMake options 填 `-DCMAKE_TOOLCHAIN_FILE=...`，Reset Cache and Reload（[01_环境准备.md](01_环境准备.md) 第 2 节） |
| 板子上运行报 `undefined symbol: mpp_buffer_sync_begin_f` | 板子 `/usr/lib` 里出厂的 MPP 库太旧 | 运行时加 `LD_LIBRARY_PATH=/userdata/mpp_build/lib`（[01_环境准备.md](01_环境准备.md) 第 4 节） |
| CMake 报 `Cannot specify link libraries for target "xxx"` | `target_link_libraries` 里写的目标名和 `add_executable` 里的不一致 | 保持一致（本工程是 `day1_yuv2h264`） |
| 编译报 `jump to label 'CLEANUP' crosses initialization` | C++ 的 goto 不能跳过带初始化的变量声明 | 变量都声明在 `main()` 开头、第一个 `CHECK` 之前 |
| 用了 `MPP_ALIGN` 编译不过 | 它在 MPP 内部头文件 `mpp_common.h` 里，不对外提供 | 自己定义 `#define ALIGN(x, a) ...` |
| adb 找不到板子 | 板子没开机，或者 OTG 线没插在 TypeC0 口 | `adb devices` 检查 |

## 3. 编码和画面的坑

| 现象 | 原因 | 解决办法 |
|---|---|---|
| `encode_put_frame` 返回错误 | 输入缓冲区是 `malloc` 出来的 | 必须用 `mpp_buffer_get` 从 DRM 内存池申请 |
| 画面斜着错位 | 整块 `fread` 进缓冲区，没有按 stride 逐行拷贝 | 参考 `read_image` 逐行拷贝 |
| 画面底部有绿条，或者颜色不对 | UV 的起始位置算成了 `width × height`，应该是 `hor_stride × ver_stride` | `buf_uv = buf_y + hor_stride * ver_stride` |
| 画面花屏、有残影，像是上一帧的数据 | 写完数据**没有调用 `mpp_buffer_sync_end`**，硬件读到的是缓存刷新之前的旧数据 | CPU 写完后调用 `mpp_buffer_sync_end(frm_buf)` |
| VLC 打不开，或者开头几秒是黑的 | 文件开头没有 SPS/PPS | 先写 `GET_HDR_SYNC` 拿到的头信息，或者设置 `EACH_IDR` |
| 取 SPS/PPS 出错 | `mpp_packet_init_with_buffer` 后 `length` 等于整个 buffer 大小 | 先 `mpp_packet_set_length(packet, 0)` 再 `GET_HDR_SYNC` |
| 程序最后卡住不退出 | 最后一帧没有设置 EOS，或者没有把剩下的 packet 取完 | `mpp_frame_set_eos(frame, 1)`，循环取到 `mpp_packet_get_eos(packet)` 为真 |
| 改了 `prep:*` 参数不生效 | 改完没有再调用 `MPP_ENC_SET_CFG` | 每次修改参数都要 SET_CFG |

## 4. 资源释放的坑

| 现象 | 原因 | 解决办法 |
|---|---|---|
| 内存一直涨 | `mpp_packet_deinit` / `mpp_frame_deinit` 没有调用 | 每个 frame 和 packet 用完都要 deinit |
| 中途失败时程序仍然返回 0 | `ret_code = 0` 放得太早 | `ret_code = 0` 永远放在 `CLEANUP:` 的前一行 |
| 同一个 buffer `mpp_buffer_put` 两次 | CLEANUP 里重复写了释放 | 每个资源只释放一次；deinit frame/packet 不会释放你自己的 buffer（只是引用计数 -1） |
| 打开了两次输出文件、申请了两次内存池 | 往下写新里程碑时，把上一个里程碑的步骤又抄了一遍 | 每个里程碑只加新步骤，前面做过的不要重复 |
