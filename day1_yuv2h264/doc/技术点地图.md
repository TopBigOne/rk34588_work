# day1_yuv2h264 技术点地图

> 一个"读 NV12 → MPP 硬件编码 → 写 .h264"的小程序，往下挖涉及的所有技术点。
> 每个点都标了**在哪学**（文档）和**在哪用**（代码），复习或面试前从这里出发。
> 最后一列 ☐ 留给自己打勾：能不看资料讲清楚了，就改成 ☑。

---

## 0. 全景：一条线串起来

```
命令行参数 ──→ Args ──→ EncoderConfig
                              │
NV12 文件 ──fread 逐行──→ DRM 缓冲区 ──sync_end──→ MppFrame ──put_frame──→ 硬件编码器
（紧密排列）   （按 stride）   （CACHABLE）              （标签）                   │
                                                                          get_packet
                                                                               ▼
.h264 文件 ←──fwrite──── std::vector<uint8_t> ←──assign── uint8_t* pos ←── MppPacket
（Annex-B 裸流）                                    （void* 转过来）       （pos + length）
```

每一个箭头背后都是一个技术点：
- 为什么要**逐行** fread？→ stride（第 1 节）
- 为什么要 **sync_end**？→ CACHABLE 内存和 DMA（第 2 节）
- 为什么 `void*` 要转成 **`uint8_t*`**？→ 指针运算（第 3 节）
- 为什么要**拷进 vector**？→ RAII 释放 packet 之后 pos 失效（第 3 节）
- 为什么 **fwrite 一次**就够？→ vector 内存连续（第 5 节）
