## 本周目标

把码流封装成 FLV 文件，再用一个极简 HTTP 服务以 chunked 方式持续输出，浏览器里用 flv.js 播放。FLV tag 的结构在第 28 周（N11）已经学过，本周重点是 HTTP 这一层。

## 学完能回答的问题

1. HTTP-FLV 和 RTMP 用的是同一种封装，区别在哪？
2. HTTP chunked 传输是什么？为什么直播流要用它？
3. 为什么国内很多直播平台网页端用 HTTP-FLV，而不是 RTMP？
4. HTTP-FLV 的延迟大概多少？和 RTMP 比呢？
