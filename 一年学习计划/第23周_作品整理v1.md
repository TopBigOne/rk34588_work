## 本周目标

把 mini NVR v1 整理成**别人 5 分钟能看懂**的作品：一个能公开的 GitHub 仓库（README、架构图、实测数据、演示 GIF），再写出简历初稿。

## 学完能回答的问题

1. 用 3 句话介绍 mini NVR：做了什么、技术难点在哪、有什么数据？
2. 架构图上每个方块，你都能讲出"为什么这样分"吗？
3. 简历上写的每一条，面试官追问三层，你答得上来吗？（挑最没把握的一条，先自己追问一遍）
4. 哪些代码是你写的，哪些是 Claude 写的样板、哪些是复用的库？被问到时怎么如实说？

## 开始前要准备好

- **素材**：
  - 性能报告（第 21 周）
  - 稳定性报告（第 22 周）
  - N10 的两张对比表（第 18 周）
  - N1/N2 的抓包截图（第 6、9 周）
  - 问题案例库
- **演示录像**：用手机拍板子屏幕上的 2×2 预览，加上一段有人走过、出框的画面，每段 10～20 秒。
- **决定公开范围**：作品仓库只放**自己写的代码和文档**。SDK 里的 demo 代码、Rockchip 的头文件和库不放进去，在 README 里写清依赖和获取方式（各开源许可证的具体要求**未核对**，拿不准的就不放）。
